# Hlemist Cinema

Nezávislý multimediální doplněk pro Kodi 21.2 Omega (Python 3).

## Stav projektu

Projekt je ve fázi základní kostry. Rozhraní doplňku a instalace z repozitáře budou připraveny jako první; vyhledávání a přehrávání přes externí služby bude doplněno až po ověření jejich oficiálních rozhraní a podmínek. Samotné zapnutí zdroje zatím neznamená, že je jeho integrace funkční.

## Bezpečnost a oprávnění

- Nevkládej hesla, API klíče ani tokeny do veřejného repozitáře.
- Přihlašovací údaje zadávej pouze lokálně v nastavení Kodi.
- Doplněk nebude obcházet DRM, placený přístup ani technická omezení služeb.
- Používej pouze obsah, ke kterému máš oprávněný přístup.
- Kód je vytvářen nezávisle; nepřebírá zdrojový kód projektů s omezující licencí.

## Technické údaje

- Kodi: 21.2 Omega
- Python: 3
- Add-on ID: `plugin.video.hlemistcinema`
- Výchozí verze: `0.1.0`
